# Sample outputs

Real annotated results from the live pipeline (`inference/pipeline.py`, via the
`/predict` endpoint), not mockups — generated by running the checked-in sample
images through all three trained detectors and saving the returned annotated image.

Thin, color-coded box outlines only (no per-box text label): amber for product,
blue for empty gap, teal for price tag. See `inference/pipeline.py:render_annotated`
for why — a densely packed shelf photo can have 100+ detections, and per-box text
labels make that unreadable rather than informative.

| File | Products | Gaps | Tags |
|---|---|---|---|
| `annotated_shelf_08.jpg` | 271 | 5 | 120 |
| `annotated_shelf_04.jpg` | 300 | 3 | 116 |
| `annotated_shelf_16.jpg` | 238 | 3 | 90 |
| `annotated_shelf_36.jpg` | 123 | 5 | 31 |

Reproduce any of these yourself:

```bash
curl -X POST http://localhost:8000/predict -F "file=@assets/samples/shelf_08.jpg"
```
